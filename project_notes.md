# MindFlow

MindFlow is a personal wellness application focused on hydration,
focus, meditation, and simple mental activities.

## Current Status

### Milestone 1 — Completed

- Python development environment
- Virtual environment
- Gemini API integration
- FastAPI backend
- Uvicorn development server
- GET API endpoint
- POST API endpoint
- LLM-backed API endpoint
- Git repository

## Architecture

Current:

PowerShell / Client
        ↓
FastAPI
        ↓
Gemini API

## Product Principles

- Start simple
- Build before over-engineering
- Minimize unnecessary LLM usage
- Validate features with real users
- Free core experience initially
- Premium features later
